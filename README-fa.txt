نسخه‌ی نصبی ساده (بدون سرور) — برای نصب روی گوشی با یک لمس
==========================================================
این بسته فقط «فایل‌های ثابت» است؛ هر گوشی/لپ‌تاپ داده‌های خودش را نگه می‌دارد (همگام نمی‌شود).
ورود با ایمیل و تب دسترسی به‌صورت آزمایشی کار می‌کند:
   مدیر:  admin@example.com  /  admin123
   علی:   ali@example.com    /  ali12345
   سارا:  sara@example.com   /  sara12345
(برای اشتراک واقعی بین پرسنل، بسته‌ی daftar-kar-server را نصب کنید.)

مراحل (۵ دقیقه):
۱. این zip را Extract کنید.
۲. همه‌ی فایل‌ها را در یک هاست دارای HTTPS آپلود کنید (مثلاً public_html هر هاست ایرانی با گواهی SSL،
   یا هر سرویس میزبانی فایل ثابت). مثال آدرس نهایی: https://your-domain.ir/daftar/
۳. آدرس را در Chrome گوشی باز کنید ← بالای تقویم دکمه‌ی «📲 نصب» ← نصب.
   (آیفون: Safari ← اشتراک ⬆ ← Add to Home Screen)
۴. برای APK: آدرس را در https://www.pwabuilder.com بدهید ← Package for Android.
